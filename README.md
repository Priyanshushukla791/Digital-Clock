# Digital Clock (Python)

A simple **Digital Clock application built using Python and Tkinter**. This program displays the current system time in a graphical window and updates every second.

## Features

* Real-time digital clock
* Automatic time update every second
* Simple graphical interface
* Built using Python Tkinter

## How It Works

The program uses the **Tkinter library** to create a GUI window and the **time module** to get the current system time. The clock updates every second using a loop function.

## Requirements

* Python 3.x
* Tkinter (usually included with Python)

## Example Output

The program opens a window showing the current time in **HH:MM:SS format** that updates every second.
